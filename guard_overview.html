Guard AI Video Generator

Long-form AI video scaffold (up to 17 minutes) with chunking + stitch pipeline.

What’s included

  • FastAPI backend for projects/jobs.
  • Job validation for 5..1020 seconds (17-minute max).
  • Chunk planning for long-duration renders.
  • FFmpeg stitcher scaffold for final clip merge.
  • Static frontend to queue jobs quickly.

How to run

./scripts/run_backend.sh

Then open frontend/index.html in your browser.

How to test

cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
PYTHONPATH=. pytest -q

Manual API and frontend test steps are documented in README.md.

API Endpoints

  • GET /health
  • POST /projects
  • GET /projects
  • POST /jobs
  • GET /jobs/{job_id}
